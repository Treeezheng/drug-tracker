# 云入口交叉检查

2026-09-13，独立代码审查。范围为 `server/cloud.mjs`、`server/vault-store.mjs`、`src/lib/vault-crypto.ts`、`src/lib/cloud-client.ts`、`src/components/CloudGate.tsx` 及对应测试；没有修改这些实现文件。此报告不是外部密码学审计或真实设备视觉测试。

发现的一项 P2 已由文件负责人修复：`logout()` 原先等待网络注销成功后才清除本地密钥 / 记录，因此断网时退出会留下已解锁页面。现在客户端先锁定，Gate 在成功和失败时都清除敏感状态并卸载记录界面；失败信息明确服务器会话可能仍有效。专项测试覆盖离线注销后导出被拒绝，以及恢复网络后的独立解锁。

本次未找到其他需立即修改的具体阻塞问题。核对重点：

- Host / Origin 使用固定配置，代理转发头不改变允许来源；写请求重新确认会话，数据接口绑定 owner。
- 云数据库在开启 WAL / 修改内容前检查表名，拒绝本机表；bootstrap 事务约束单账户，云构建标记与本机产物分离。
- 数据和包装密钥成对事务保存；whole-vault CAS、错误确认重试和 generation 检查避免普通并发覆盖与锁定后重新恢复明文。
- 随机 nonce、AAD 绑定、信封大小 / 编码 / KDF 上限及累计 JSON 字节限制与客户端 / 存储契约一致。重新检查了此前已修复的大字符串累计大小问题。

独立运行加密、vault 存储及 cloud-client 三组测试，**46 项通过，0 失败**。包括错误密码 / 篡改 / owner、共享大字符串预检、并发 CAS、断网保存、丢失确认、初始化重试、导入修订与离线退出。运行仅使用合成数据和临时数据库，没有读取或迁移正式健康库。云 API 负责人的独立测试结果不计入这里的 46 项。

部署配置还做了静态契约检查：四个非秘密环境变量、4312 回环端口、完整 `/drug` 路径、独立用户 / 数据目录、无账户密码，以及文档本地链接。当前 Mac 没有 Caddy 或 systemd，尚未执行它们的运行时配置验证；尚未进行 Azure VM、真实 DNS / 证书、iPhone 云端流程和恢复演练。

仍需保留的真实边界包括：当前在线使用且只有现存记录快照；导出的 CSV / PDF / JSON 为明文；同源根页面必须可信；服务器可见认证 / 同步元数据；没有恶意旧密文回滚防护或独立可信客户端分发。详细说明见 [版本与加密边界](./editions-and-encryption.md) 和 [Azure 部署指南](./azure-vm-deployment.md)。
