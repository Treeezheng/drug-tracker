# 项目来源与署名说明

Drug Tracker 起于 **Abraham Zheng** 的真实个人需求。项目构想、产品要求、功能优先级、设计取舍及迭代反馈由 Abraham Zheng 提供。三页面结构、较少的视觉干扰、先在本机运行、密码解锁、按药品区分的记录与汇总等，属于这些产品决定。

**项目应用代码全部由 AI（Codex / OpenAI）生成与实现。** Abraham Zheng 的贡献是构想、需求与产品/设计方向，不声称本人手写了这些应用代码。使用的开源框架、库和字体仍按各自作者与许可证归属；它们不是本项目自行创作的代码或资产。

本项目是围绕个人需求开展的实验。参考官方药品标签、实现模型公式、通过软件测试，分别说明来源选择或程序行为；它们不等于经过临床验证，也不能证明个人浓度预测、剂量建议或安全结论成立。药品目录可记录的范围与已实现参考模型的范围必须分别描述。

当前先提供本机运行与密码访问控制。自托管云端、跨设备同步和端到端加密属于后续准备方向；只有在实际实现与验证后，才应将它们写成已经交付的能力。
